# Web Development Skills

## HTML
- Semantic tags: `<header>`, `<main>`, `<section>`, `<article>`, `<footer>`
- Proper heading hierarchy (`h1` → `h6`)
- Alt attributes on all images
- Forms with proper labels and validation

## CSS
- Use Flexbox & CSS Grid for responsive layouts
- Media queries for mobile-first design
- Consistent color palette (use CSS variables)
- Smooth transitions & animations
- Google Fonts for typography

## JavaScript
- DOM manipulation (querySelector, addEventListener)
- Fetch API / Axios for data
- Form validation
- Smooth scrolling & modals
- Lazy loading for images

## Best Practices
- Mobile-first responsive design
- Fast load times (minify CSS/JS, optimize images)
- Accessibility (WCAG 2.1, ARIA labels, keyboard navigation)
- SEO (meta tags, Open Graph, semantic HTML)
- Cross-browser testing

## Tools
- VS Code + Live Server
- Chrome DevTools
- Lighthouse for performance audits
- Git for version control

## Frameworks (optional)
- Bootstrap / Tailwind CSS for styling
- React / Vue for dynamic apps
