# wp-content/

WordPress content directory — everything site-specific lives here.

| Item | Purpose |
|------|---------|
| `themes/custom-portfolio-theme/` | Active custom theme (main codebase) |
| `uploads/` | Media library files (git-ignored, local only) |
| `plugins/` | Plugins — defaults removed, none installed |
| `index.php` | Silence-is-golden stub (prevents directory listing) |
| `debug.log` | PHP/WordPress debug log (`WP_DEBUG_LOG`; git-ignored) |
